## GitHub Push 전 보안 체크리스트

- [ ] `.env` 파일이 올라가지 않았는가? (`.gitignore` 확인)
- [ ] API Key(`VITE_YOUTUBE_API_KEY`, `VITE_GEMINI_KEY`)가 코드에 하드코딩되어 있지 않은가?
- [ ] Firebase 설정(`firebaseConfig`)의 민감 정보 노출 여부 확인
- [ ] 실제 사용자 데이터·로그가 포함되지 않았는가?
- [ ] `node_modules/`, `dist/`, `.env` 가 `.gitignore`에 있는가?
- [ ] `.env.example` 을 만들어 필요한 키 목록만 공유

> ⚠️ **중요**: `VITE_` 프리픽스 환경변수는 빌드 시 **번들에 그대로 포함**되어
> 브라우저에서 노출된다. API 키를 완전히 숨기려면 백엔드 프록시가 필요하다.
> → `21_HANDOFF_BACKEND.md` 참고.

## 알려진 이슈 / 주의사항

| 이슈 | 상태 | 대응 |
|---|---|---|
| YouTube quota 초과 (403/429) | 환경 의존 | 캐싱 적용함. 발표 전 테스트 최소화 + 태평양 자정 리셋 |
| Firestore Listen 채널 차단 (`access control checks`) | 확장/네트워크 | 시크릿 모드/확장 끄기로 회피. 기능엔 영향 없음 |
| MV 임베드 차단 영상 | 영상별 정책 | 코드로 강제 불가. 데모는 임베드 되는 곡으로 |
| 검색 10분 컷 | 의도된 동작 | 긴 정식곡 드물게 누락 가능. 필요시 600→900초 |
